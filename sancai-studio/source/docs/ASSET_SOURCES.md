# 素材、工艺来源与使用边界

## 模板

`src/templates` 的四款卡通形象由代码原创绘制，宽颈丰厚马体、长颈驼峰、拱手冠帽、抬臂甲胄分别参考唐三彩的广义题材特征。没有直接打包、抠图或去水印使用用户参考目录里的照片和 VCG 插画；不宣称这些卡通是某件文物的精确复原。

原始参考目录为 `../../唐三彩素材`。逐图视觉分析及未核实的馆藏/许可边界见父目录《唐三彩_项目构建与Codex实现方案.md》第 2 节。

## 第二轮重绘

按用户提供的“载乐骆驼文物照片—艺术化插画”对照，提取舒展比例、连续轮廓、细线装饰和织毯层次的处理方式，新建 `horse-v2.ts`、`camel-v2.ts`、`official-v2.ts`、`guardian-v2.ts`。均为独立编写的 SVG path，不把参考照片、插画、水印或棋盘格打包为可涂色模板。

骏马减少大眼与分块式关节线，改为侧面小眼、连贯头颈、四肢外轮廓和鞍毯流苏；骆驼调整长颈、昂首、双峰与毯边；人物调整头身比例、衣褶及卷云甲饰。参考表达方式不表示这些新图形是文物的精确复原。

版本 1 模板文件保留。该轮新作默认使用版本 2，旧作品按其记录版本加载；不要直接改动已交付版本的区域与坐标，否则会改变原作品。缓存同时包含模板内容的签名以避免开发迭代时读取旧画面。

## 当前造型与用户确认

第三轮按博物馆资料与本地实物参考重画四款结构，参考链接及观察边界见 [第三版结构记录](appearance-v3.md)。随后用户指出马的参考照片有畸变：先收窄颈部，再将头部降低并向肩部靠近，头后至肩部跨度由约 339 缩短为约 248 个模板单位。用户确认短颈版本后，才继续剩余功能。

当前新作使用 `horse-v5.ts`；骆驼、文官、守护俑使用各自 v3。马的 v1—v4、其他图形的 v1/v2 均保留。马颈调整是当代二维造型设计，不声称获得某匹马的测量数据或还原某件特定文物。最新用户确认优先于初稿厚颈/短肢等比例建议。

公开站点只包含代码绘制路径与必要内容。`artifacts` 中的博物馆照片与开发用对照页不进入 `dist` 生产包；其中公开馆方照片的来源仍保留于结构记录中，不将用户目录中其他照片的许可一并推定为开放。

## 布料模板

`src/rendering/product.ts` 的帆布袋、T 恤、手帕几何从旧 `caomu-rubu` 项目复用。帆布袋和 T 恤来自此前用户提供模板的矢量重绘，不能改称完全不依赖参考的原创轮廓。源图为课程目录 `素材/帆布包.jpg` 与 `素材/T恤.png`；原图未改动。

## 文化信息

知识卡存放于 `src/content/craft.ts`，每张附来源。研究依据为已核查的机构页面，详见计划第 21 节：

- [中国非物质文化遗产网：唐三彩烧制技艺](https://www.ihchina.cn/ccr_detail/14450/)
- [中国国家博物馆：三彩方柜](https://www.chnmuseum.cn/zp/zpml/kgfjp/202111/t20211116_252219.shtml)
- [河南博物院：三彩马及牵马胡俑](https://www.chnmus.net/ch/collection/appraise/details.html?id=512156296641873343)
- [郑州市文物局：黄冶唐三彩窑址](https://wwj.zhengzhou.gov.cn/country/3176735.jhtml)
- [The Met：Horse and rider](https://www.metmuseum.org/art/collection/search/44805)

本应用采用相关洛阳传承资料的二次烧成体验路径。网页配色、纹样和流釉是当代数字创作，HEX 与釉量选项不是实物配方，动画时长不是实际工艺耗时。

## 字体与图标

中文与英文字体使用用户设备系统字体回退，不从第三方 CDN 加载字体。图标来自已安装 `lucide-react`；许可随 npm 包提供。
