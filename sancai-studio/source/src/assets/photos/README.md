# 唐三彩实物照片

将照片放进本目录。文件名使用下表的名称，扩展名支持 `.jpg`、`.jpeg`、`.png`、`.webp`、`.avif`。每个名称只放一个文件。保存后刷新开发预览，发布版需重新运行 `npm run build`。

| 文件名（不含扩展名） | 对应位置 |
| --- | --- |
| `overview` | 首页唐三彩介绍 |
| `horse` | 探索页和选坯说明里的三彩马 |
| `camel` | 双峰骆驼 |
| `official` | 文官俑 |
| `guardian` | 天王俑 |
| `vessel` | 三彩器皿 |
| `musicians` | 三彩骆驼载乐俑 |
| `kiln` | 河南关联图下方的窑址或制陶照片 |

如果照片拍的是特定藏品，可以在 `src/content/objects.ts` 的对应条目填写 `photoCredit`，注明器物名称、馆藏或摄影来源。页面会保留完整图片比例。访问者点照片可打开原图。
